# Notes

Working files for medium and large tasks: briefs, plans, work splits, session notes.
Name them `YYYY-MM-DD-short-name-kind.md`, for example `2026-11-15-player-stats-plan.md`.

When a task is finished:
- Anything lasting moves to the right place (decision record, domain rules, architecture docs).
- The note file can stay as history, or be deleted. Nothing important should live only here.
